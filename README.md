## 🚀 Featured Projects

### 🔥 [Heatmap Analytics Platform](https://heatmap.com)
> Web analytics & heatmap SaaS — recording, replaying, and visualizing user behavior on websites.

**Stack:** `Nuxt.js` `Vue 3` `TypeScript` `Node.js` `PostgreSQL`

Built and maintained core frontend systems including reusable component libraries (`DashboardToolbar`, `DataTable`), tooltip directive system with 5 variants (scorecard, heatmap, analyze, info, drag-info), composable-based state caching, and domain-separated API client architecture.

---

### 🤖 Halo Decision Trees Platform
> AI-powered decision tree engine with a full Tools & Widgets extensibility system — think ElevenLabs Agents, but for structured form flows.

**Stack:** `TypeScript` `Vue.js` `Form.io` `Node.js` `PostgreSQL`

Engineered a complete Tools system (circuit breakers, rate limiting, request deduplication, caching, event-sourced state management) and a WidgetService for AI-driven dynamic form generation. Widgets include AuthenticationWidget, PlanSelectionWidget, ManagedDependentsWidget, and more.

---

### 🛠️ VS Code AI Workflow Builder *(in progress)*
> A visual drag-and-connect workflow builder inside VS Code for orchestrating AI agents client-side.

**Stack:** `React Flow` `VS Code Webview API` `TypeScript` `Node.js`

Features sequential agent consultations, logic gates, and user clarification flows — built as a VS Code extension with a full Webview-based UI.

---

### 🏪 POS System
> Point-of-sale system for retail operations with real-time inventory management.

**Stack:** `Vue.js` `Nuxt.js` `TypeScript` `Node.js` `PostgreSQL`

---

### 📦 Warehouse & Analytics Dashboard
> Internal warehouse management system with analytics and reporting dashboards.

**Stack:** `Nuxt.js` `Vue 3` `TypeScript` `PostgreSQL` `Neon DB`

---

### 🌐 TallyHub Ghana ([tallyhubgh.com](https://tallyhubgh.com))
> Full-stack web application deployed on a Hostinger VPS with CI/CD automation.

**Stack:** `Nuxt.js` `TypeScript` `Neon PostgreSQL` `Nginx` `PM2` `Let's Encrypt`

Set up full production infrastructure: PM2 process management, Nginx reverse proxy, SSL via Let's Encrypt, DNS configuration, and a `deploy.sh` automation script.

---

### 🧩 Franlind Transport Services – Multi-Step Form App
> Multi-step React form application for transport services client.

**Stack:** `React` `Vite` `Tailwind CSS` `Lucide React` `TypeScript`

---

### 📊 SSE Data Visualization (Streaming Insights)
> TypeScript function for parsing structured markdown tables from SSE-streamed AI insight data.

**Stack:** `TypeScript` `Node.js` `Server-Sent Events`

Built `extractTablesFromInsightStream` — a streaming parser that reconstructs structured table data from chunked LLM output for real-time analytics dashboards.
